# Pelocore Branding Pack

A complete starter identity for **pelocore**, the open-source Peloton → FIT → COROS activity bridge.

## Included

- Primary horizontal logo in SVG
- Reverse and monochrome logo variants
- Standalone brand mark variants
- Favicon and app icon SVGs
- PNG icon exports at common sizes
- `favicon.ico`
- GitHub social-preview artwork (SVG + PNG)
- Brand guide with colors, typography, spacing, usage, and naming guidance
- CSS custom properties for the palette
- The generated concept board used as visual reference

## Recommended placement

For a repository root, copy:

```text
icons/favicon.ico → favicon.ico
social/github-social.png → repository social preview
logo/logo-horizontal.svg → README / documentation
```

The app icon can be used anywhere a square mark is needed.

## Design rationale

The mark is a pair of opposing motion arrows wrapped around a center node. It reads as a bridge or synchronization loop rather than a sports-specific object, which keeps the identity useful as pelocore grows beyond one activity source or destination.

**Tagline:** Bridge your workouts. Own your data.
